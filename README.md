# URBAN HAVEN APARTMENTS

This is a landing page for a fictional company, Urban Haven, that offers house rental services.
This application is built pure CSS and HTML.

![image](./images/readme-hero-section.png)

#### check out live demo https://charles-254.github.io/urban-haven-landing-page/

## Getting Started

### Clone this repository:

git clone https://github.com/charles-254/urban-haven-landing-page.git

### Navigate to the repository:

cd urban-haven-landing-page

### Install the necessary dependencies:

npm install

### start up the local server:

npm run dev
